Team Guide: Run the LIBERO Simulator from Scratch (Windows)

This repo has been verified on Windows + NVIDIA GPU + conda environment groot. The stack is two processes that must stay separate. Do not run the server and the simulator in the same Python environment.

Terminal 1 (conda groot, uses the GPU)     Terminal 2 (libero_uv venv)
run_gr00t_server.py  ------------------►   rollout_policy.py
Loads weights, listens on port 5555        MuJoCo / LIBERO sim client

The official Linux / uv flow is in Isaac-GR00T/examples/LIBERO/README.md. The steps below are the path this team uses to reproduce the setup from zero on Windows.

0. Machine requirements

  • Windows 10 or 11
  • NVIDIA GPU, 16GB+ VRAM recommended (RTX 4090 or similar)
  • Anaconda or Miniconda already installed: https://www.anaconda.com/download
  • About 20GB free disk. The LIBERO weights are about 6.5GB. The first server start also downloads the Cosmos VLM backbone.
  • A Hugging Face account
  • Git, with submodule support

1. Clone the repo

Open PowerShell and clone with submodules (LIBERO lives in a submodule):

git clone --recurse-submodules <repo-url> MI_VLA
cd MI_VLA

If you already cloned without submodules:

git submodule update --init Isaac-GR00T/external_dependencies/LIBERO

From this point on, every command assumes you are here:

cd Isaac-GR00T

2. Get Hugging Face access (do this first)

Both models are gated. Opening the website is not enough. You must request access while logged in, wait until the page says you have access, then create a token and log in on this machine.

2.1 Create or log in to Hugging Face

  1. Open https://huggingface.co/join in a browser.
  2. Create an account, or log in if you already have one.
  3. Stay logged in for the next steps. If you are not logged in, the Agree / Request access button will not work.

2.2 Request access on both model pages

Open each link below. On the model page you should see a gate / license box. Click Agree and access repository or Request access, fill in the form, accept the NVIDIA license, and submit.

  1. https://huggingface.co/nvidia/GR00T-N1.7-LIBERO — LIBERO finetuned weights (the files you download in step 4).
  2. https://huggingface.co/nvidia/Cosmos-Reason2-2B — gated VLM backbone. Every GR00T checkpoint loads this on first use, including the local LIBERO folder. If you skip this one, the server will fail even after the weights are on disk.

NVIDIA license accept is usually instant. Refresh the page. You have access when the gate form is gone and you can see Files / the model card. If the page says pending, wait for email approval before continuing.

2.3 Create a Read token

  1. Open https://huggingface.co/settings/tokens
  2. Click New token.
  3. Name it something like groot-libero.
  4. Set permission to Read.
  5. Create the token and copy it immediately. Hugging Face will not show the full token again.

Do not paste this token into Slack, git, or the repo. Treat it like a password.

2.4 Log in on this machine (after groot exists)

You cannot run huggingface-cli login until the groot env is installed (step 3). After that:

conda activate groot
huggingface-cli login

When prompted, paste the token. Or set an environment variable for the current PowerShell session only:

$env:HF_TOKEN = "<your-token>"

Without both page approvals and a local login, download and server start fail with GatedRepoError or 401.

3. Install the inference env (conda groot, once)

Must be Python 3.12. Python 3.13 is missing some wheels and will break later installs.

In PowerShell, from Isaac-GR00T:

conda create -n groot python=3.12 -y
conda activate groot
conda install -c conda-forge "ffmpeg<8" -y
pip install -e .

Notes:

  • torchcodec only supports FFmpeg 4, 5, 6, or 7. That is why the conda line pins ffmpeg<8.
  • flash-attn does not install on Windows. That is expected. The server falls back to sdpa attention.
  • pip install -e . can take a while (PyTorch and friends).

Sanity check:

python -c "import gr00t, torch; print('gr00t ok, cuda=', torch.cuda.is_available())"

Expected output includes: gr00t ok, cuda= True

If cuda= False, the GPU driver / CUDA / PyTorch install is wrong. Fix that before downloading weights.

Now log in to Hugging Face (from 2.4):

huggingface-cli login

4. Download the LIBERO weights

Hugging Face does not accept a nested path like nvidia/GR00T-N1.7-LIBERO/libero_10 as --model-path. You must download the libero_10 folder to disk first.

Still in conda groot, from Isaac-GR00T:

conda activate groot
hf download nvidia/GR00T-N1.7-LIBERO `
  --include "libero_10/config.json" `
  --include "libero_10/embodiment_id.json" `
  --include "libero_10/model-*.safetensors" `
  --include "libero_10/model.safetensors.index.json" `
  --include "libero_10/processor_config.json" `
  --include "libero_10/statistics.json" `
  --local-dir checkpoints/GR00T-N1.7-LIBERO

This downloads about 6.5GB. When it finishes you should have:

checkpoints/GR00T-N1.7-LIBERO/libero_10/
  config.json
  embodiment_id.json
  model-00001-of-00002.safetensors
  model-00002-of-00002.safetensors
  model.safetensors.index.json
  processor_config.json
  statistics.json

These weights are already in .gitignore. Do not git add them and do not push them to GitHub (GitHub rejects files over 100MB).

5. Install the LIBERO sim env (once)

The simulator client is a separate virtual environment under libero_uv. Do not mix it with groot. groot is only for the GPU server. libero_uv is only for MuJoCo / LIBERO.

Activate groot first. The setup script uses groot’s Python 3.12 to create the venv:

conda activate groot
cd Isaac-GR00T
powershell -ExecutionPolicy Bypass -File gr00t/eval/sim/LIBERO/setup_libero.ps1

This installs robosuite, MuJoCo, LIBERO, and patches Windows to use WGL instead of EGL. It can take 10–20 minutes.

Success looks like:

Env OK ...
Setup done.
Sim python: ...\libero_uv\.venv\Scripts\python.exe

Sim Python path:

gr00t/eval/sim/LIBERO/libero_uv/.venv/Scripts/python.exe

.venv is gitignored. Do not commit it.

6. Run with two terminals

Keep both terminals open. Start the server first and wait until it is listening. Only then start the client.

6.1 Terminal 1 — Policy server

It is normal for this window to stay occupied. You will not get a prompt back until you stop the server.

cd Isaac-GR00T
conda activate groot
python gr00t/eval/run_gr00t_server.py `
  --model-path checkpoints/GR00T-N1.7-LIBERO/libero_10 `
  --embodiment-tag LIBERO_PANDA `
  --use-sim-policy-wrapper

Wait until you see:

Server is ready and listening on tcp://0.0.0.0:5555

The first launch also downloads Cosmos-Reason2-2B and can take several minutes. Ignore these messages if they appear:

  • flash_attn is not installed
  • albumentations upgrade suggestion
  • FutureWarning from dit.py

To stop the server: press Ctrl+C in this window. If that does nothing, close the terminal. Closing the terminal is fine; it kills the process and frees port 5555.

6.2 Terminal 2 — Sim client

Open a second PowerShell. Do not activate groot here. Use the libero_uv Python.

On Windows you must pass --video-dir explicitly. The default path is the Linux path /tmp/... and will fail. Start with 1 parallel env.

cd Isaac-GR00T
$py = "gr00t/eval/sim/LIBERO/libero_uv/.venv/Scripts/python.exe"
$env:MUJOCO_GL = "wgl"
& $py gr00t/eval/rollout_policy.py `
  --n-episodes 1 `
  --n-envs 1 `
  --policy-client-host 127.0.0.1 `
  --policy-client-port 5555 `
  --max-episode-steps 720 `
  --n-action-steps 8 `
  --env-name libero_sim/KITCHEN_SCENE3_turn_on_the_stove_and_put_the_moka_pot_on_it `
  --video-dir tmp_sim_videos

When it finishes you will see success rate printed. Videos are written to:

Isaac-GR00T/tmp_sim_videos/

To skip video recording, use --video-dir none.

7. Switch tasks

You do not need to restart the server. Only change the client’s --env-name and run the client command again.

Good starter tasks:

libero_sim/KITCHEN_SCENE3_turn_on_the_stove_and_put_the_moka_pot_on_it
libero_sim/pick_up_the_black_bowl_from_table_center_and_place_it_on_the_plate
libero_sim/turn_on_the_stove

The full task list is at the end of Isaac-GR00T/examples/LIBERO/README.md (Libero 10 / Goal / Object / Spatial).

8. Troubleshooting

Symptom Fix
GatedRepoError or 401 Accept both HF model pages, create a Read token, then huggingface-cli login inside groot.
Address already in use Port 5555 is taken by an old server. Close that terminal, or start the server with --port 5556 and point the client at the same port.
Server terminal never returns a prompt Expected. It is listening in the foreground. Ctrl+C or close the window.
Could not load libtorchcodec / FFmpeg conda activate groot, then conda install -c conda-forge "ffmpeg<8" -y
Sim errors about EGL / OpenGL Windows needs MUJOCO_GL=wgl. Re-run setup_libero.ps1.
Video write to /tmp/... fails Add --video-dir tmp_sim_videos on the client.
Want to skip video --video-dir none
Large n-envs hangs or crashes On Windows start with --n-envs 1
GitHub push rejected (file too large) checkpoints/ and *.safetensors are gitignored. Do not git add them.

9. Do not commit these

  • Isaac-GR00T/checkpoints/ — model weights, several GB
  • Isaac-GR00T/gr00t/eval/sim/LIBERO/libero_uv/.venv/ — sim environment
  • Isaac-GR00T/tmp_sim_videos/ — eval videos (optional to ignore)

Quick recap: Get HF access on both pages → token → clone → conda groot + pip install → huggingface-cli login → download weights → setup_libero.ps1 → start server → start client.
