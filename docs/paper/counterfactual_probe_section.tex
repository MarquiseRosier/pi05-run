\section{Controlled Counterfactual Perturbation}
\label{sec:counterfactual}

\subsection{Motivation}

The pipeline of Sections~A--C is, at every stage, \emph{selection-based}. Feature
discovery nominates a target by how unusually it activates; circuit tracing
expands backward from that target; causal validation ablates the resulting
circuit and compares it against random feature sets. Positives are the
observations that activated the feature, and negatives are other observations
judged semantically related.

At no point does the experiment \emph{set} the cause. Positives and negatives
differ in many uncontrolled ways simultaneously: different scene, different
objects, different robot pose, different task phase. When a circuit responds
differently across them, the design cannot attribute that difference to any one
factor. The effect is visible in the negative-control results of Section~C,
where target ablation is exactly $0.0000$ on every negative set. That is true,
but close to tautological: the negative sets were chosen partly because the
target feature is inactive on them.

This section supplies the missing ingredient, an intervention on the
\emph{input} for which we know by construction exactly what changed and exactly
what did not.

\paragraph{Plain statement of the method.}
Freeze one moment of a simulated scene. Render it twice. Between the two
renders, change the colour of exactly one object and nothing else: not the
robot, not the camera, not the physics, not the other objects, and not the
random noise the policy samples. Push both images through the policy. Any
difference in the network's internals is caused by that object's pixels,
because nothing else differed. Then repeat on a second object that looks
identical but is not the one the task refers to, to check that the network is
responding to \emph{that particular object} rather than to any coloured patch.
Finally, use this known cause to audit the circuit tracer: if the parents it
finds for a feature genuinely carry that feature's information about the
object, they should respond to the object's recolour and not to the control's.

\subsection{Preliminaries: the arithmetic of a transcoder circuit}
\label{sec:circuit-math}

We restate the quantities the rest of this section is written in terms of.

Each instrumented MLP $\ell$ carries a sparse time-conditioned transcoder. With
$x_{\ell}$ the MLP input and $\tau$ the flow timestep,
\[
\tilde{x}_{\ell} = x_{\ell}\odot(1+\gamma_\tau)+\beta_\tau,
\]
\[
z_{\ell} = \mathrm{ReLU}\left(W^{\ell}_{\mathrm{enc}}\tilde{x}_{\ell}+b^{\ell}_{\mathrm{enc}}\right),
\qquad
\hat{y}_{\ell} = W^{\ell}_{\mathrm{dec}} z_{\ell}+b^{\ell}_{\mathrm{dec}},
\]
where $z_{\ell}\in\mathbb{R}^{B\times T\times d_{\mathrm{features}}}$ and
$d_{\mathrm{features}}=16\,d_{\mathrm{model}}=16384$. Component $z_{\ell,i}$ is
\emph{feature $i$ at layer $\ell$}. A feature is identified by the triple
$(\ell,\tau,i)$, written $\mathtt{L}\ell\!:\!\tau\!:\!\mathtt{F}i$, because the
same index at a different flow time is a different computational node. The
policy integrates $n$ Euler steps with $\tau = 1 - \mathrm{step}/n$, so the
recorded flow times are $\{1, 1-1/n, \ldots, 1/n\}$.

\paragraph{Probe mode versus replacement mode.}
In probe mode the policy runs unchanged and $z_\ell$ is only recorded: it is a
measurement, not a cause. In replacement mode $\hat{y}_\ell$ \emph{is} the MLP
output, so $z_\ell$ lies on the computational path and derivatives with respect
to it are meaningful. Circuit tracing therefore requires replacement mode; the
counterfactual probe of this section runs in probe mode, on the unmodified
policy.

\paragraph{What an edge is.}
In replacement mode, feature $j$ at a later layer $\ell'$ has pre-activation
$a_{\ell',j,p}$ at action-token position $p$. Two positional choices are part
of the definition and are easily left implicit by mistake. The target is
evaluated at a \emph{single} position $p^{\star}$. The source is summed over
\emph{all} of its token positions, since a parent may contribute from anywhere
in the chunk. The edge is therefore
\begin{equation}
\mathrm{edge}(i \rightarrow j)
\;=\;
\sum_{t=1}^{T}
z_{\ell,i,t}\,
\frac{\partial a_{\ell',j,p^{\star}}}{\partial z_{\ell,i,t}},
\label{eq:edge}
\end{equation}
a signed quantity. The derivative is obtained as a vector--Jacobian product:
$a_{\ell',j,p^{\star}}$ is a scalar, so a single reverse pass through the
replacement model yields the whole gradient with respect to $z_\ell$, with
attention mixing and normalisation along the path accounted for.

How $p^{\star}$ is chosen depends on the node's depth. For the traced target
it is the token at which the target feature most strongly activated on that
observation, supplied by feature discovery. For a parent that is itself
expanded at the next depth, it is the source position at which that parent's
contribution to its own child was largest, retained when the parent was found.
Both are recorded per observation, so a replication can recover them.

Eq.~\ref{eq:edge} is the first-order Taylor term for turning feature $i$
\emph{off}: since $a_{\ell',j}(z_{\ell,i}) - a_{\ell',j}(0) \approx z_{\ell,i}\,
\partial a_{\ell',j}/\partial z_{\ell,i}$, the edge estimates how much of $j$'s
pre-activation is attributable to $i$ being active rather than silent. This is
the sense in which it is an ``attribution'' and not merely a sensitivity.

Two factors in Eq.~\ref{eq:edge} are worth separating. The derivative is
\emph{fixed wiring}: it depends on the weights and the surrounding activations,
not on how strongly $i$ fired. Multiplying by $z_{\ell,i}$ converts it into an
\emph{attribution for this input}, so a strongly wired parent that did not fire
contributes nothing here.

\paragraph{What an edge is not.}
Eq.~\ref{eq:edge} is a first-order local quantity. It describes how
$a_{\ell',j}$ would move under an infinitesimal change to $z_{\ell,i}$ at this
operating point. It does not establish that the edge carries any particular
semantic content, and it need not survive a large intervention. The gap between
an attribution being large and an edge meaning what we take it to mean is
precisely what this section is designed to probe.

\subsection{Hypotheses}
\label{sec:hypotheses}

Each hypothesis is stated with the observation that would falsify it. The
decision rules are fixed in advance and restated, with thresholds, in
Section~\ref{sec:verdicts}.

\paragraph{H1, object selectivity.}
Transcoder features respond to a controlled appearance change of the object the
task designates more than to a matched appearance change of a visually
identical object it does not, once perturbation size is accounted for. \emph{Falsified if} the two responses are
comparable once perturbation size is accounted for (Eq.~\ref{eq:sel-px}), which
would indicate the features track generic pixel change. Note that the two
objects necessarily differ in screen position as well as in task designation,
so H1 on its own cannot separate those; H2 is what addresses that.

\paragraph{H2, referent versus position.}
The selectivity in H1 follows the object the \emph{language refers to}.
\emph{Supported if}, over pixel-identical images, swapping the prompt to refer
to the other object inverts the selectivity. \emph{Falsified if} selectivity is
unchanged or strengthens for the original object. A selectivity that weakens
without inverting is recorded as \emph{partial}: language modulates the
response but does not determine it. All three readings presuppose that the
swap demonstrably moved the referent (Section~\ref{sec:grounding}): the policy
must react to the prompt at all, and its behaviour must re-anchor on the other
object. Otherwise H2 is \emph{untestable} on this scene.

\paragraph{H3, circuit corroboration.}
The \emph{parents} of a circuit traced upstream of a target are more
\emph{selective} for the perturbed object than random features matched in
layer and flow time and drawn from those the scene exercises. \emph{Falsified
if} the selectivity enrichment of Eq.~\ref{eq:sel-enrich} is near $1$ at the
head of the influence ranking, which would indicate the traced edges do not
carry the perturbed property beyond what any active feature at those layers
carries. Whether the parents are also enriched for a manipulation of a
different kind qualifies a supported verdict (Eq.~\ref{eq:specificity}) but
does not overturn it. The target node itself is excluded from the test,
because it was nominated for responding.

\medskip
\noindent
H1 and H2 concern the model. H3 concerns the \emph{method}: it uses a known
cause to audit whether attribution-based tracing recovers the features that
actually carry that cause.

\subsection{Method}

\subsubsection{Paired same-state counterfactual}

Fix a LIBERO task and a seed and advance the simulator to a state $s$. Let
$R(s,\theta)$ denote the rendered observation at state $s$ under scene
appearance parameters $\theta$, with $\theta_0$ the unmodified scene and
$\theta_c^{(d)}$ the scene with object $c$ recoloured at dose $d$.

\paragraph{Reduction over tokens.}
A single forward pass produces, for each layer $\ell$ and denoise step with flow
time $\tau$, a sparse code $z_{\ell,\tau}\in\mathbb{R}^{B\times T\times
d_{\mathrm{features}}}$ with $B=1$ and $T=50$ action tokens. We reduce over the
batch and token axes by a maximum, giving one scalar per feature,
\begin{equation}
\tilde{z}_{\ell,\tau,i}
=
\max_{b,t}\; z_{\ell,\tau,b,t,i}
\;\in\;\mathbb{R},
\qquad
\tilde{z}_{\ell,\tau}\in\mathbb{R}^{d_{\mathrm{features}}} .
\label{eq:reduce}
\end{equation}
The maximum is used rather than the mean because the question is whether a
feature fired anywhere in the chunk, not how broadly it fired; a feature active
at a single action token is still active.

\paragraph{The paired difference.}
With $\epsilon$ a \emph{single} flow-matching noise sample shared by both
forward passes, the signed per-feature difference is
\begin{equation}
\delta_{\ell,\tau,i}(c,d)
=
\tilde{z}_{\ell,\tau,i}\!\left(R(s,\theta_c^{(d)}),\,\epsilon\right)
-
\tilde{z}_{\ell,\tau,i}\!\left(R(s,\theta_0),\,\epsilon\right).
\label{eq:delta}
\end{equation}
The full vector $\delta_{\ell,\tau,\cdot}$ is recorded for every layer, flow
time and condition; nothing below relies on a truncated summary of it.

Two summaries of Eq.~\ref{eq:delta} are used and should not be conflated. The
\emph{layer response} is the Euclidean norm over the feature axis, averaged over
the recorded flow times,
\begin{equation}
D_{\ell}(c,d)
=
\frac{1}{|\mathcal{T}|}\sum_{\tau\in\mathcal{T}}
\left\lVert \delta_{\ell,\tau,\cdot}(c,d) \right\rVert_2 ,
\label{eq:layer-response}
\end{equation}
and the \emph{per-feature response} is the magnitude of a single component,
$|\delta_{\ell,\tau,i}|$. Eq.~\ref{eq:layer-response} drives the headline
selectivity of Table~\ref{tab:cf-main}; the per-feature quantity drives the
ranking of Section~\ref{sec:zscore} and the circuit audit of
Section~\ref{sec:validation-method}.

\medskip
\noindent
Three properties make Eq.~\ref{eq:delta} an intervention rather than a
comparison.

\begin{enumerate}
\item \textbf{The state is frozen.} Physics is never stepped between the two
renders. Only $\theta$ changes, so joint positions and velocities, camera pose
and lighting are bit-identical. Once every recolour at a state has been
reverted, the baseline is re-rendered and required to match the original
exactly; the same exact-restore check runs on the liveness probe at start-up.
\item \textbf{The noise is shared and seeded.} $\pi_{0.5}$ integrates a flow
from a sampled $x_1\sim\mathcal{N}(0,I)$. Sampling independently per pass would
leave $\delta$ dominated by that draw. We sample once per replicate from a
generator seeded deterministically by (seed, state, draw index) and pass the
same tensor to both passes explicitly, so a run is reproducible bit for bit and
any single cell can be regenerated alone.
\item \textbf{Closed loop is excluded.} Running a rollout per condition would
allow the trajectories to diverge, after which $\delta$ reflects different
robot states rather than the recolour. All measurements are open-loop at a
fixed $s$. Between states, the simulator is advanced by executing the first $k$
actions of the policy's own unperturbed plan.
\end{enumerate}

\paragraph{Replication unit.}
A \emph{cell} is one combination of state $s$, noise draw $n$ and dose $d$
under one prompt. The target and placebo are measured in every cell; the null
control and the positive control have no dose and are measured once per
(state, draw). Cells are the replication unit for every error bound below. Noise draws are exchangeable replicates of the policy's own stochastic
inference; states are distinct robot poses along its plan.

\paragraph{Why colour.}
The recolour overwrites the per-geometry colour field of the target body in the
loaded MuJoCo model, then re-renders. It changes no geometry, no mass, no
contact and no position, so the object's footprint, occlusion and physics are
preserved exactly. Colour is in that sense the cheapest available intervention
that leaves everything else fixed.

\subsubsection{The matched placebo and the footprint adjustment}
\label{sec:placebo}

The control is a second object of the \emph{same type} in the same scene. In
\texttt{libero\_spatial} the suite instantiates two instances of the same mesh,
\texttt{akita\_black\_bowl\_1} and \texttt{akita\_black\_bowl\_2}, and the task
names one of them. Perturbing the other gives a control matched on mesh,
material, colour and size, differing only in table position and in whether the
prompt refers to it. This is a substantially tighter control than a
semantically related but different object, because the appearance change itself
is nearly identical.

The other instance is the \emph{non-referent}, not an irrelevant object: the
policy must discriminate against it to solve the task, so a response to it is
a response to the bowl the task says to leave alone. H1 therefore asks whether
features weight the referent more than the non-referent, not whether they
ignore the non-referent.

Write $D(c)$ for the layer response pooled over all $|\mathcal{L}|=18$
instrumented layers, all $|\mathcal{T}|=n$ flow times, and all cells under the
task prompt,
\[
D(c) = \frac{1}{|\mathcal{L}|\,|\mathcal{T}|\,|\mathcal{K}|}
\sum_{\kappa\in\mathcal{K}}\sum_{\ell\in\mathcal{L}}\sum_{\tau\in\mathcal{T}}
\left\lVert \delta^{(\kappa)}_{\ell,\tau,\cdot}(c) \right\rVert_2 ,
\]
where $\mathcal{K}$ is the set of cells $(s,n,d)$ and $\delta^{(\kappa)}$ the
difference measured in cell $\kappa$. The raw selectivity is
$\mathrm{Sel} = D(\mathrm{target})/D(\mathrm{placebo})$, a ratio of means over
the same cells.

Because the two instances occupy different screen positions, their perturbed
pixel footprints are not exactly equal. To ask whether the difference is more
than a difference in how much of the image moved, we divide by a measure of
perturbation size,
\begin{equation}
\mathrm{Sel}_{\mathrm{adj}}
=
\frac{D(\mathrm{target})}{D(\mathrm{placebo})}
\;\bigg/\;
\frac{S(\mathrm{target})}{S(\mathrm{placebo})},
\qquad
S(c)\in\Bigl\{\,|\mathcal{P}(c)|,\;\lVert \Delta I(c)\rVert_2 \,\Bigr\},
\label{eq:sel-px}
\end{equation}
where $\mathcal{P}(c)$ is the set of changed pixels and $\Delta I(c)$ the
image-space difference, each computed over \emph{every} camera the policy
sees (counts summed, norms combined in quadrature) and pooled over the same
cells as $D$. Measuring on one camera would be wrong here: the agentview
camera and the objects are static, so a bowl's footprint there is identical at
every state, while the wrist camera's view of the same bowl changes with the
arm and can carry most of the perturbation. Both choices of $S$ are reported. The pixel count ignores how far each pixel moved and does
not change with dose; the image norm captures magnitude and does change with
dose. The image norm is therefore the \emph{primary} normaliser for the H1
decision, and the pixel count is reported alongside.

\paragraph{Uncertainty.}
Each cell yields its own $\mathrm{Sel}_{\mathrm{adj}}$, and we report the mean,
standard deviation, minimum and maximum across cells together with a percentile
bootstrap interval for the pooled ratio obtained by resampling cells with
replacement ($2000$ draws). Cells are not independent: the doses within one
(state, draw) share a render and a noise sample, and the draws within one state
share the robot pose. The spread is therefore also reported over (state, draw)
clusters with doses pooled within, which is the coarser but honest unit. With
few clusters neither interval is tight; that is the state of the evidence, and
both $n$ are reported next to the numbers. The pre-registered H1 rule uses the
minimum across cells, which is the stricter statement and does not rest on an
independence assumption.

\paragraph{What the adjustment assumes.}
Eq.~\ref{eq:sel-px} is exact only if the response grows linearly in the
perturbation size. We measure this directly as a dose elasticity,
\begin{equation}
\eta(c) = \frac{\log D(c,d_2) - \log D(c,d_1)}
                {\log S(c,d_2) - \log S(c,d_1)},
\qquad S = \lVert \Delta I\rVert_2,
\label{eq:elasticity}
\end{equation}
between consecutive doses $d_1<d_2$, pooled over states and draws. Linear
response gives $\eta=1$. If $\eta$ departs markedly from $1$ the adjustment
over- or under-corrects and the unadjusted ratio is to be quoted alongside.

\paragraph{Robustness across summaries.}
$D$ is a Euclidean norm over $16384$ features averaged over $18$ layers, so the
layers with the largest activations dominate it, and a selectivity read off $D$
is mostly a statement about those layers. Two scale-free summaries are reported
alongside: the ratio formed from the \emph{relative} layer response
$\lVert\delta_{\ell,\tau,\cdot}\rVert_2/\lVert\tilde{z}_{\ell,\tau,\cdot}\rVert_2$,
and the geometric mean over layers of the per-layer selectivities
$D_\ell(\mathrm{target})/D_\ell(\mathrm{placebo})$, with its range and the
number of layers above $1$. The H1 decision is made on
$\mathrm{Sel}_{\mathrm{adj}}$; the conclusion is called \emph{robust} only if all
three summaries fall on the same side of $1$.

\subsubsection{Controls and guards}
\label{sec:controls}

Each control rules out a specific way the result could be spurious; each guard
aborts the run rather than letting it produce a plausible number.

\paragraph{Null control.}
The \emph{same} baseline observation is pushed through the policy twice with the
same noise, and $\delta$ is computed between those two passes, in every cell.
This measures the nondeterminism floor. A run is valid only if the largest null
$D$ is at most $5\%$ of $D(\mathrm{placebo})$; otherwise the paired comparison
is compromised and H1 is recorded as invalid rather than decided.

\paragraph{Liveness control.}
Before any measurement the target is recoloured to full saturation and
re-rendered, and the pixel change is required to be non-zero; the perturbation
is then reverted and the baseline required to be restored exactly. Without this,
a stale render cache yields $\delta=0$ everywhere, and an identity self-check
cannot detect that condition, since comparing a cached frame against the frame
it was cached from is trivially zero.

\paragraph{Positive control.}
A null floor says what no manipulation does; a positive control says what a
manipulation \emph{known} to matter does. Swapping the prompt is such a
manipulation: its effect on the action is $g$ (Eq.~\ref{eq:grounding}), and its
latent response is available at no cost from the two baselines already
computed in every cell. We report $D(\mathrm{prompt\ swap})$ and the target and
placebo responses as fractions of it, so a recolour response is read on the
scale of what a behaviour-changing input produces on these layers, not as a
bare number.

\paragraph{Dose response.}
Each perturbation is applied at several doses along a linear interpolation
toward the target colour. A response caused by the recolour should grow with
dose; Eq.~\ref{eq:elasticity} quantifies how, and monotonicity in dose is
reported for target and placebo separately.

\paragraph{Shape guard.}
The tensor shapes handed to the policy are recorded on the first pass and every
later pass is checked against them. A paired comparison across differently
shaped inputs is not a paired comparison.

\paragraph{Weight-load guard.}
The policy loader in use returns a randomly initialised model, with only a
printed warning, when its state dictionary fails to load, and a partial load
passes silently. Every script that builds the policy records what the loader
reported and aborts on any missing parameter. A run on random weights cannot
occur without exiting non-zero.

\subsubsection{Separating referent from position}
\label{sec:grounding}

H1 compares two objects at two screen positions, so task relevance and position
are confounded. In \texttt{libero\_spatial} they cannot be separated by moving
objects, because the suite \emph{defines} its target by position: every task is
of the form ``the black bowl'' followed by a spatial relation.

They can be separated by changing the language. The suite constructs its tasks
by placing the same target object in different regions, so some sibling task's
prompt refers to whichever region our placebo occupies. That prompt is found
automatically from the sibling problem definitions. Running both prompts over
pixel-identical images with shared noise leaves language as the only
difference.

Selectivity is computed \emph{within} each prompt: for a given prompt, both the
target and the placebo response are differences against that same prompt's
baseline. The prompt's own large effect on the activations therefore cancels,
and what is compared across rows is a ratio of differences, not the activations
themselves. Since the images are identical across prompts, $S$ is identical too,
and the comparison is made on the raw ratio.

The control is interpretable only if the policy responds to language at all. We
therefore measure \emph{prompt grounding} in every cell, the relative change in
the \emph{unperturbed} action chunk between the two prompts,
\begin{equation}
g = \frac{\lVert a(\mathrm{prompt}_{\mathrm{alt}}) - a(\mathrm{prompt}_{\mathrm{task}})\rVert_2}
         {\lVert a(\mathrm{prompt}_{\mathrm{task}})\rVert_2}.
\label{eq:grounding}
\end{equation}
If the mean $g$ is below $0.01$ the swap manipulated nothing and H2 is
untestable on this scene. We report $g$ alongside the action effect of the
perturbation itself for scale.

\paragraph{Manipulation check: did the referent move?}
$g$ shows that the policy processed the new words. It does not show that the
policy now targets the other bowl. Because the prompt names ``the black
bowl'', recolouring the bowl the policy is going for changes the action far
more than recolouring the other one, so the action's own sensitivity reveals
the behavioural referent. Write $A(c)$ for the relative action change under
recolour of object $c$, and the \emph{behavioural anchor}
\begin{equation}
\mathrm{anchor}(\mathrm{prompt}) = \frac{A(\mathrm{target})}{A(\mathrm{placebo})}
\label{eq:anchor}
\end{equation}
under each prompt. Under the task prompt the anchor should exceed $1$. Under
the sibling prompt the referent has moved only if the anchor falls
\emph{below} $1$; if it stays above $1$ the swap moved words but not the
referent, and H2 is untestable on this scene with this prompt, whatever $g$
says. This check uses the action, not the latents, so it is independent of
the quantity H2 is decided on. It matters here because the sibling phrase is
chosen by the region the placebo occupies, and a phrase such as ``next to the
ramekin'' can be true of a bowl that sits between the plate and the ramekin
as well.

\subsubsection{Nominating a trace target}
\label{sec:zscore}

The probe nominates the feature whose circuit will be traced. Nomination is
decided once, under the task prompt, by a rule written to disk with the
nominee, and every downstream stage reads that file rather than re-ranking.

\paragraph{Ranking.}
A feature's raw selectivity divides its target response by its placebo
response, and placebo responses differ by an order of magnitude across depth,
so raw selectivity cannot choose \emph{which layer} to trace from. We rank
instead by a layer-standardised response,
\begin{equation}
z^{\mathrm{std}}_{\ell,i}
=
\frac{\overline{|\delta|}_{\ell,i}-\mu_\ell}{\sigma_\ell},
\label{eq:zstd}
\end{equation}
where $\overline{|\delta|}_{\ell,i}$ is feature $i$'s mean per-feature response
over the cells in which it ranked among the $K$ largest responders at its
layer and flow time, and $\mu_\ell$, $\sigma_\ell$ are the mean and standard
deviation of that quantity over the features of layer $\ell$ that ranked
among the top $K$ anywhere. This is a truncated population: $z^{\mathrm{std}}$
measures position within the layer's responders, not within all $16384$
features. Since $K$ is the same for every layer, the comparison across layers
remains well posed, which is the property required here.

\paragraph{Filters.}
Three criteria are applied before ranking, each ruling out a specific bad
nominee.
\begin{enumerate}
\item \textbf{Reproducibility.} The feature must rank among the top $K$
responders in at least $25\%$ of its layer's cells, where a cell here is one
(state, draw, dose, flow time) under the task prompt. Without this a feature
that fired once against a near-zero placebo tops the ranking on one
observation.
\item \textbf{Depth.} The feature must sit at layer $\ell\ge 4$. A shallower
target has almost nothing upstream, so its trace fans out sideways rather
than finding a circuit.
\item \textbf{Placebo.} From the recorded full deltas, the feature's exact
mean placebo response at its peak flow time must be at most half its exact
mean target response. The placebo acts as a filter, not as a denominator, so a
placebo response of exactly zero is admissible rather than divided by.
\end{enumerate}
The peak flow time is the $\tau$ at which the feature's target response was
largest, and the nominee is named $\mathtt{L}\ell\!:\!\tau\!:\!\mathtt{F}i$ in
the key format the tracer consumes.

\subsubsection{Using the counterfactual to audit the traced circuit}
\label{sec:validation-method}

Let $\mathcal{C}$ be the set of \emph{parent} nodes of a circuit traced upstream
of the nominated target; the target node is excluded because it was nominated
for responding to the probe, and scoring it would make the test circular. Each
parent is a node $(\ell,\tau,i)$ and is scored at \emph{its own} flow time: the
probe step is $\mathrm{round}((1-\tau)\,n)$, and the node's response is the mean
of $|\delta_{\ell,\tau,i}|$ over the task-prompt cells. Because every delta was
recorded in full, every parent has a known response; there are no unmeasured
nodes.

\paragraph{Exercised nodes.}
A feature the scene never activates has a genuine zero response here, which is
different from an unknown one and different again from a feature that was
active and did not move. A node is \emph{exercised} if it is active in some
baseline or moves under the target perturbation in some cell. Unexercised
parents are excluded from the mean and their count reported; the
\emph{exercised fraction} bounds what the test can say.

\paragraph{Matched null.}
Write $\bar{\Delta}_{\mathcal{C}}(c)$ for the mean response over exercised
parents under condition $c$. A random draw over all $16384$ features would be
mostly unexercised zeros and would make any active set look enriched. The null
is therefore matched: for each exercised parent, a random feature is drawn
from the exercised features at the \emph{same} layer and flow time, and the
draw's mean response $\bar{\Delta}^{(m)}(c)$ is computed. The \emph{same}
drawn features are evaluated under every condition, so per-draw ratios are
defined. With $M$ such draws,
\begin{equation}
\mathrm{Enrich}(\mathcal{C},c) = \frac{\bar{\Delta}_{\mathcal{C}}(c)}
{\frac{1}{M}\sum_{m}\bar{\Delta}^{(m)}(c)},
\qquad
p = \frac{1+\left|\{\,m:\bar{\Delta}^{(m)}(c)\ge\bar{\Delta}_{\mathcal{C}}(c)\,\}\right|}{M+1}.
\label{eq:enrich}
\end{equation}
The $+1$ in numerator and denominator makes the estimate conservative and keeps
$p>0$ at finite $M$. Because circuit nodes are connected and therefore
correlated, the effective sample size is below $|\mathcal{C}|$; the test is one
of whether the set as a whole is unusual, not of independent evidence per node.

\paragraph{Why response enrichment cannot decide H3.}
$\mathrm{Enrich}(\mathcal{C},\mathrm{target})>1$ says the parents respond more
than random features. It does not say they carry the perturbed property.
Attribution favours features that are active and high-variance, and such
features respond more to \emph{any} manipulation, so a generically responsive
set clears this bar while carrying nothing in particular. Two additions fix
this.

First, the statistic is a ratio of ratios. Let $\mathrm{Sel}_{\mathcal{C}} =
\bar{\Delta}_{\mathcal{C}}(\mathrm{target})/\bar{\Delta}_{\mathcal{C}}(\mathrm{placebo})$
be the circuit's own selectivity and $\mathrm{Sel}^{(m)}$ the same ratio on
draw $m$. Then
\begin{equation}
\mathrm{SelEnrich}(\mathcal{C}) = \frac{\mathrm{Sel}_{\mathcal{C}}}
{\frac{1}{M}\sum_{m}\mathrm{Sel}^{(m)}},
\qquad
p = \frac{1+\left|\{\,m:\mathrm{Sel}^{(m)}\ge\mathrm{Sel}_{\mathcal{C}}\,\}\right|}{M+1},
\label{eq:sel-enrich}
\end{equation}
which divides out the responsiveness the circuit shares with the random sets.
Reporting $\mathrm{Sel}_{\mathcal{C}}$ alone is not enough: a matched random
set at these layers is itself highly selective, because selectivity is a
property of the layer as much as of the feature.

Second, a specificity check. The probe measures a manipulation of a different
kind, the prompt swap, on the same cells. With $\mathcal{M}$ the set of such
manipulations,
\begin{equation}
\mathrm{Spec}(\mathcal{C}) = \frac{\mathrm{Enrich}(\mathcal{C},\mathrm{target})}
{\max_{c\in\mathcal{M}}\mathrm{Enrich}(\mathcal{C},c)} .
\label{eq:specificity}
\end{equation}
The placebo is excluded from $\mathcal{M}$: it is the matched control for the
same manipulation and already the denominator of Eq.~\ref{eq:sel-enrich}.
$\mathrm{Spec}$ qualifies a supported verdict rather than deciding it. If
Eq.~\ref{eq:sel-enrich} passes and $\mathrm{Spec}>1$, the parents are
\emph{object-specific}. If it passes and $\mathrm{Spec}\le1$, the parents are
as enriched for a language change as for the recolour, which is what a circuit
that computes the referent from both vision and language would look like; the
verdict is \emph{supported, not specific}, and those parents are not a
colour-only handle for steering. $\mathrm{Spec}$ alone cannot falsify,
because that same pattern is produced by a legitimate referent circuit. What
separates a referent circuit from a generically responsive set is
Eq.~\ref{eq:sel-enrich}: generic responsiveness scales the target and placebo
responses alike and leaves the selectivity ratio at the random set's.

\paragraph{Where the decision is taken.}
At large $|\mathcal{C}|$ the mean over the circuit and the mean over a draw
both concentrate, so any systematic difference, however small, drives $p$ to
its floor $1/(M+1)$; a selectivity enrichment of $1.05$ over $1700$ nodes is
``significant'' and means nothing. This applies to Eq.~\ref{eq:sel-enrich} as
much as to Eq.~\ref{eq:enrich}. The decision is therefore taken where $p$ is
informative: parents are ordered by their traced influence, and H3 is decided
on the \emph{head} of that ranking, the top $10$ parents, which is also the
tracer's strongest claim. The full circuit is required to agree in direction
($\mathrm{SelEnrich}>1$) but no $p$ is asked of it. Both are reported.

\paragraph{Enrichment as a function of circuit size.}
Eqs.~\ref{eq:enrich} to \ref{eq:specificity} are also evaluated over the top
$50$, top $200$ and all parents. A tracer whose ranking is informative shows
enrichment that is strong at the head and decays; a flat profile says the
ranking carries no information about the property, and no amount of pruning
would help. The contrast between the head and the full set separates ``this
circuit is wrong'' from ``this graph was pruned too loosely'', which are
different defects with different fixes.

\paragraph{Selection and test use different evidence.}
The nominee is chosen from the probe's data and is excluded from the test. The
parents are chosen by the tracer from dataset observations and gradients in the
replacement model, which never sees the probe's data; they are then tested on
the probe's data. No quantity is both selected on and tested with.

\subsection{Hypothesis verdicts}
\label{sec:verdicts}

To be completed from Tables~\ref{tab:cf-main}--\ref{tab:cf-validation}. The
rules below are the ones the code applies; each run writes its verdict, the
rule it applied and the numeric thresholds side by side, under
\texttt{verdict}, \texttt{decision\_rule} and \texttt{thresholds} in the
artefacts named.

\paragraph{Why these thresholds.}
None is tuned to the data; each is a conventional or structural choice fixed
before the run. The null floor bound of $5\%$ of the placebo response is the
level below which the floor could not change the direction of a ratio near
$1$. The grounding bound of $0.01$ is one per cent of the action norm, below
which the prompt swap cannot be distinguished from a no-op. The consistency
bound of $25\%$ requires a nominee to appear in at least one cell in four, the
weakest rule that excludes a feature seen only under one state or one draw.
The depth bound $\ell\ge4$ leaves at least four layers of parents to trace.
The exact-selectivity bound of $2\times$ is the smallest integer ratio that
makes ``responds more to the referent'' unambiguous. The exercised-fraction
bound of one half requires that the scene speak for the majority of the
circuit. The selectivity and specificity bounds are both $1$, the value at
which a circuit is indistinguishable from a matched random set and at which an
intervention is no more informative than an unrelated one; neither is a tuned
quantity. The head of $10$ is the smallest stratum at which a mean is still a
mean and the Monte-Carlo $p$ is still informative. $\alpha=0.05$ is
conventional.

\paragraph{H1.}
\RESULT{supported, weak, falsified or invalid}. \emph{Invalid} if the largest
null $D$ exceeds $5\%$ of $D(\mathrm{placebo})$. Otherwise \emph{supported} if
the pooled $\mathrm{Sel}_{\mathrm{adj}}$ with $S=\lVert\Delta I\rVert_2$ exceeds
$1$ and so does its minimum over cells; \emph{weak} if only the pooled value
does; \emph{falsified} otherwise. Quote the unadjusted ratio alongside if
$|\eta - 1|$ is large, and call the conclusion robust only if the relative
and per-layer summaries agree in direction
(\texttt{h1.robustness.agree\_in\_direction}).
(\texttt{decision\_metrics.json}, \texttt{h1.verdict}.)

\paragraph{H2.}
\RESULT{supported, partial, falsified or untestable}. \emph{Untestable} if there
is no sibling prompt, if mean $g<0.01$, or if the behavioural anchor of
Eq.~\ref{eq:anchor} stays at or above $1$ under the sibling prompt (the
referent did not move; \texttt{h2.referent\_check}). Otherwise, with
$\mathrm{Sel}_{\mathrm{task}}>1$: \emph{supported} if
$\mathrm{Sel}_{\mathrm{alt}}<1$; \emph{falsified} if
$\mathrm{Sel}_{\mathrm{alt}}\ge\mathrm{Sel}_{\mathrm{task}}$; \emph{partial}
otherwise. If $\mathrm{Sel}_{\mathrm{task}}\le1$ there is no selectivity to
follow the referent and H2 does not apply. (\texttt{h2.verdict}.)

\paragraph{H3.}
\RESULT{supported and object-specific, supported but not specific, falsified,
or inconclusive}. \emph{Inconclusive} if fewer than half the parents are
exercised by the scene. \emph{Falsified} if the selectivity enrichment of
Eq.~\ref{eq:sel-enrich} over the top $10$ parents by influence is at most
$1$ or has $p\ge0.05$, or if the full circuit's selectivity enrichment is at
most $1$. Otherwise \emph{supported}, qualified as \emph{object-specific} if
the specificity of Eq.~\ref{eq:specificity} at the head exceeds $1$ and as
\emph{not specific} if it does not. Response enrichment alone never decides,
and specificity alone never falsifies. (\texttt{validation.json},
\texttt{h3\_verdict}, \texttt{decision\_stratum\_nodes}.)

\subsection{Threats to validity}
\label{sec:threats}

\paragraph{Does the manipulation isolate what we claim?}
Within a single comparison, yes: the two renders share state, camera and noise,
and the pixel difference is confined to the perturbed object. Across
comparisons the target and placebo differ in screen position as well as task
relevance. Eq.~\ref{eq:sel-px} addresses the footprint part of this and the
prompt swap the relevance part, but residual position confounding remains and
is reported as such.

\paragraph{Are the circuit and the probe talking about the same inputs?}
Not exactly, and this bounds what H3 can establish. The circuit is traced on the
dataset observations where the target feature fires, whereas the probe measures
on environment renders of one held-fixed task. A parent that is genuinely
upstream of the target on the tracing distribution may never activate in the
probe's scene. Because every delta is recorded, such a parent is identified as
unexercised and reported, rather than being silently absent; but a parent that
is exercised and does not respond remains ambiguous between ``this edge does not
carry the property'' and ``it carries it on the dataset but not on this
scene''. A positive H3 result does not suffer that ambiguity. The exercised
fraction is what a reader should look at first.

\paragraph{Does the prompt swap move the referent?}
Not necessarily, which is why Eq.~\ref{eq:anchor} gates H2. The sibling
phrase is chosen by the region the placebo occupies, and a spatial phrase can
be true of both bowls at once. When the anchor stays above $1$ under the
sibling prompt, the run says so and H2 is recorded as untestable rather than
partial. Whether the policy \emph{would} re-ground under an unambiguous
phrase is a separate question this design does not answer; an override prompt
is available for a follow-up. A reading of the untestable case that is still
informative: the policy's behaviour, and its features, stayed with the bowl
the task prompt named even when told otherwise in ambiguous words.

\paragraph{Why do the states differ so much?}
The response can be several times larger at a later state, with the agentview
footprint unchanged. The arm has moved, so the wrist camera's view of the
bowl has changed and the policy is closer to acting on it. This is why $S$ is
measured over every camera and why the spread is reported over (state, draw)
clusters and not only over cells; with two states the cluster spread is
essentially the difference between them.

\paragraph{Is the null for H3 fair?}
Matching on layer, flow time and exercise makes the null ``a random active
feature here''. It is stricter than an unmatched draw and less strict than a
null matched on baseline activation magnitude. A circuit whose parents are
simply the most active features at their layer could be enriched under the
response test without carrying the property, which is precisely why the
verdict rests on Eqs.~\ref{eq:sel-enrich} and~\ref{eq:specificity} instead.

\paragraph{Can specificity be misread?}
Yes, in one direction. A set enriched as much for the prompt swap as for the
recolour has two readings: generically responsive features, or a circuit that
genuinely computes the referent from vision and language together. The
specificity statistic cannot tell them apart, and a rule that falsified on it
alone would wrongly reject the second. The two are separated by
Eq.~\ref{eq:sel-enrich}: a referent circuit is more object-selective than a
random set at its layers, a generically responsive one is not. This is why
specificity qualifies and selectivity decides.

\paragraph{Is the traced graph a circuit?}
Not necessarily. The tracer expands a bounded number of nodes but records
every edge above its attribution floor, then prunes by cumulative influence,
so a permissive threshold yields thousands of nodes spanning most of the early
layers. A set that large is a slice of the network rather than a circuit
hypothesis, and its mean is close to the matched random mean by construction.
Table~\ref{tab:cf-strata} is what distinguishes the two readings: if the head
of the influence ranking is enriched and the tail is not, the finding is real
and the pruning is too loose; if the profile is flat, the ranking is
uninformative for this property. The node count is reported with every
verdict.

\paragraph{Does the measurement answer the question?}
$\delta$ is measured on the features the transcoders expose, so any claim is
about \emph{transcoder features} rather than about the underlying MLP basis. A
response not visible in the sparse code is not visible here.

\paragraph{Is the effect size meaningful?}
Only relative to the null floor, which the design forces to be measured rather
than assumed, and relative to the placebo. Both are reported in every table.

\paragraph{Is colour the right variable?}
Colour is convenient because it leaves geometry and physics untouched, and in
this suite it is also load-bearing: every prompt names ``the black bowl'', so
recolouring a bowl removes it from the set the noun phrase denotes. A
behavioural effect is therefore expected when the \emph{referent} is
recoloured and not when the non-referent is, and the action column of
Table~\ref{tab:cf-main} is a behavioural test of H1 in its own right. Two
bowls of the same colour mean the prompt's spatial phrase, not colour, picks
the referent; the recolour perturbs the noun, not the spatial relation. In a
task whose prompt did not name a colour, the same recolour would be expected to
move behaviour little, and feature-level selectivity would then be the only
claim available.

\paragraph{Scope.}
One task, one seed, a small number of states, draws and doses. The design
controls confounds tightly but samples narrowly, and the intervals in
Table~\ref{tab:cf-main} are correspondingly wide. Generalisation across tasks,
objects and perturbation types is untested.

\subsection{Reproducibility}

Every stage is a script with recorded configuration and a deterministic seed.
Each probe run also writes \texttt{provenance.json}: the git commit and
whether the tree was dirty, Python and platform, the versions of the policy,
simulator and tensor libraries, the accelerator, and a SHA-256 of the
transcoder checkpoint, so that a reported number can be tied to the exact code
and weights that produced it. The pipeline and its artefacts are:

\begin{enumerate}
\item \textbf{Probe.} Paired counterfactual at frozen states. Writes the full
signed deltas and baselines for every cell and condition
(\texttt{latents/}), the per-cell decision quantities
(\texttt{decision\_metrics.json}, \texttt{h1\_cells.csv}), every measurement
including the positive control (\texttt{counterfactual\_summary.json},
\texttt{measurements.csv}), the tensor shapes
(\texttt{observation\_shapes.json}), provenance (\texttt{provenance.json}) and
the rendered baseline, perturbed and difference images.
\item \textbf{Report.} Computes Table~\ref{tab:cf-layers}, ranks candidates by
Eq.~\ref{eq:zstd}, applies the three filters of Section~\ref{sec:zscore} with
exact placebo responses from \texttt{latents/}, and writes the nominee and the
rule to \texttt{nominated\_targets.json}.
\item \textbf{Discovery.} Collects the top-activating dataset observations and
token positions the tracer requires for the nominee.
\item \textbf{Trace.} Expands a circuit backward from the nominee in
replacement mode (\texttt{graph.json}).
\item \textbf{Validate.} Scores the traced parents against \texttt{latents/}
using Eq.~\ref{eq:enrich} and writes \texttt{validation.json}.
\end{enumerate}

Target and placebo objects are selected automatically from the task's own
problem definition, using the declared object of interest plus a sibling
instance of the same object type, and the sibling prompt from the sibling
problem whose target occupies the placebo's region, so none of these choices
is made by the experimenter.

\paragraph{Failure modes that abort rather than pass silently.}
The following are checked at run time and stop the run rather than producing a
plausible number: a policy whose pretrained weights did not fully load; a stale
render cache or an invisible target, via the liveness control; a baseline that
is not restored exactly after a recolour is reverted; a perturbation that
changes no pixels; drifting tensor shapes between conditions, via the shape
guard; a nomination stage that finds no feature meeting all three filters,
which reports the rejections by criterion instead of tracing the best available
candidate; and, for H2, a prompt swap that did not move the behavioural
referent, which yields \emph{untestable} rather than a graded verdict.
